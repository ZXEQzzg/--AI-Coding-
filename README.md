# 🏡 合租生活管家 (CoLiving Hub)

[img](img.png)

> 面向毕业季合租青年与都市青年的智能协同生活管理平台。
> 让合租不再有尴尬催账、推诿打扫与公用物资短缺，打造充满温度、秩序与尊重的合租生活空间。

---

## 📖 项目简介 (Overview)

在都市合租生活中，室友们常常面临诸多痛点：
- **费用纠葛**：水电燃气公摊算不清，小钱不好意思催，多方转账错综复杂；
- **卫生推诿**：值日安排口头约定容易遗忘，打扫标准不一引发摩擦；
- **物资短缺**：垃圾袋、纸巾、洗洁精“谁都在用，谁都不买”，直到断货才尴尬发现；
- **沟通隔阂**：作息冲突、外来访客等敏感问题不好当面开口，缺乏温和非暴力的协商渠道；
- **房管运维复杂**：合租大屋租约、房间面积分摊、新老室友交接及公告广播缺乏统一后台。

**合租生活管家**提供了一站式、数字化、有温度的解决方案，整合费用智能平账、保洁轮值排班、日用物资预警、公约协商投票、独立日常留言板以及房管综合治理后台，让合租生活清晰、透明、温馨。

## ✨ 核心特性 (Key Features)

### 1. 📊 今日总览看板 (Today's Dashboard)
- **核心状态一览**：租金收缴与租期倒计时卡片，重要动态随时掌握。
- **房屋置顶公告**：显示房管发布的最新紧急通知或日常提示，支持中文/英文双语角色呈现。
- **我的专属待办**：当前选定用户的今日保洁任务、未结算欠款/应收款一键查看。
- **状态快捷入口**：今日打扫一键打卡、物资告急预警直达、快速发起记账或提议。

### 2. 💰 智能 AA 记账与债务平账算法 (Expenses & Min-Cash-Flow)
- **灵活分摊模式**：
  - **均摊模式 (Equal)**：全员平摊；
  - **精确分摊 (Exact)**：按个人实际使用金额精确拆分；
  - **房间比例 (Room Share)**：按房间面积/基准租金权重分摊大额水电气费。
- **图论简化债务算法 (Min-Cash-Flow Greedy)**：
  - 自动将错综复杂的 $N$ 人多向借贷网络压缩简化为最少转账笔数；
  - 避免“A 转 B、B 转 C、C 转 A”的繁琐流程，大幅降低室友转账摩擦。
- **结算与明细**：
  - 支持“一键结清两人之间全部账单”；
  - 支持单笔分摊独立确认结算；
  - 分类过滤（房租、电费、水气、宽带、日常物资、维修等）。

### 3. 🧹 公共保洁轮值与换班机制 (Cleaning Roster & Swap)
- **多区域分工**：涵盖厨房操作台、洗手间浴室、客厅走廊、阳台垃圾倒放等。
- **执行与打卡附言**：打卡支持细项勾选与文字说明（如“洗手池已消毒擦拭”），增加合租信任感。
- **智能换班申请**：室友临时加班或外出，可发起指定日期和区域的“换班对调申请”，对方确认后自动调整排班表。
- **荣誉榜与周排班生成**：
  - 统计打卡率与准时率，激励共同维护居住卫生；
  - 支持房管/值日生一键滚动生成新一周排班计划。

### 4. 🧻 公用物资储备与一键采购分摊 (Supplies & Restock)
- **三级健康度预警**：物品状态动态分类（存量充裕、储备告急、断货耗尽）。
- **微信/群聊提醒一键复制**：一键生成友好的物资缺货清单文本，可直接粘贴发送至微信合租群。
- **一键采购联动记账**：采购人员点击“我已采购”，系统自动弹出 AA 记账窗口并预填物资名称与品类，采购与平账无缝打通。

### 5. 📜 合租生活公约与协商投票 (Pacts & Consensus)
- **全屋公约签署**：作息安静时段、公共厨房使用守则、朋友留宿报备准则，全员签署亮灯生效。
- **公投提案表决**：涉及大额添置或新规则时发起表决，全屋透明支持/反对投票。
- **非暴力沟通便签墙**：以温和、尊重的便签形式表达生活感受，支持点赞支持与标记处理。

### 6. 💬 独立生活留言板 (Message Board)
- **独立生活化板块**：与规则公约彻底解耦，记录温馨合租日常。
- **丰富主题分类**：日常唠嗑/聚餐、温和生活提醒、室友夸夸墙、借物借用求助、临时行程外出报备。
- **深度互动体验**：支持匿名发布开关、点赞互动、多条盖楼回复以及“标记为已解决/已阅”。

### 7. 🛡️ 房管综合治理中心 (Admin Console)
- **房间资产管理**：各房间编号、面积、朝向、租金标准设置，实时关联入住成员。
- **全屋运行指标**：房屋总租金、租约剩余倒计时、租金收缴进度、保洁合规率与累计公共支出。
- **成员权限控制**：室友档案维护、房管权限指定、搬入搬出管理。
- **公告广播发布**：支持发布紧急/普通房屋公告，置顶全屋广播。
- **系统审计日志**：自动记录关键管理事件，支持在数据混乱时一键恢复初始化体验。

### 8. 🎨 自然原木风设计与日/夜间主题 (Warm Wood Aesthetic & Dark Mode)
- **原木生活美学**：采用温暖沉稳的木质调配色（浅米原木 `#FDFBF7`、胡桃木深棕 `#8B5E3C`、柔和咖啡色 `#2C2218`），搭配精致质感阴影与圆角层次，拒绝冷冰冰的机械感。
- **舒适夜间模式**：右上角一键切换夜间模式，使用深暖灰木系（`#1C1917` / `#292524`）与琥珀金重点强调，护眼舒适不刺眼。

### 9. 🌐 系统级中英文智能双语切换 (Bilingual Localization)
- **智能分离系统与用户内容**：
  - 系统所有导航、指标名、状态标签、分类、按钮、公约规范及管理文字均支持中文 / 英文流畅切换；
  - 严格保持用户发表的真实留言、回复、备注、物品名称及室友姓名原样不变；
  - 角色徽章自动本地化（例如：`房屋置顶公告 · 林晨 (房管)` $\leftrightarrow$ `Pinned House Announcement · 林晨 (House Admin)`）。

## 🚀 快速上手 (Getting Started)

### 环境依赖
- **Node.js**: v18.0.0 或更高版本
- **包管理器**: npm、pnpm 或 bun

### 1. 克隆代码与进入目录
```bash
git clone <repository-url>
cd coliving-hub
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动本地开发服务
```bash
npm run dev
```
启动成功后，浏览器访问：`http://localhost:3000`

### 4. 代码类型检查
```bash
npm run lint
```

### 5. 构建生产包
```bash
npm run build
```
编译产物将存放在 `dist/` 目录下。

## 💡 核心设计与算法亮点 (Highlights)

### 1. 最小现金流债务简化算法 (Min-Cash-Flow Algorithm)
在合租场景中，多人在不同时间垫付不同费用（例如 A 垫付了水费、B 垫付了燃气费、C 垫付了保洁用品）。如果直接结算，每个人之间互相转账十分混乱。

本系统实现了净额贪心结算算法：
1. **净资产结算统计**：统计每个成员在所有支出中的 `实际支付金额 - 应分摊金额`，计算出净盈余/净欠款；
2. **贪心最大匹配**：每一轮选出**最大债权人**（应收款最多）与**最大债务人**（应付款最多），执行匹配结算，直到所有人的净值归零；
3. 将传统 $O(N^2)$ 的多向还款关系压缩为至多 $N-1$ 笔交易，大幅降低室友转账心智负担。

### 2. 纯净双语隔离策略 (Pure I18n Isolation)
区别于粗暴的全量翻译，本系统严格区分：
- **静态系统标识符**：通过 `i18n.ts` 集中管理，包括表单标签、操作动作、统计卡片、分类枚举等，随语言开关切换；
- **动态用户数据流**：用户输入的房屋留言、聊天回复、记账附言、便签内容和姓名保持原生输入状态，既符合真实的国际化合租场景，又保证了数据一致性。
