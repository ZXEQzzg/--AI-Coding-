## 项目背景

这是我在美团招聘笔试 AI Coding 环节提交的作品。原题如下：

> **题目：合租生活管家**
>
> **背景：** 年轻人合租时常面临房租水电分摊不清、公共区域清洁排班混乱、共用物品消耗无记录等问题，容易引发室友矛盾。
>
> **任务：** 使用 AI Coding 工具，设计一个「合租生活管家」，支持费用 AA 分摊、清洁值日排班、公共物品登记与提醒、室友公约管理。
>
> **建议：** 可结合你了解到的用户痛点或需求自由设计产品；不必追求技术细节，优先呈现产品结构和功能设计；UI 做一个适合毕业季年轻人的样式，饱和度低，交互流畅不复杂，要有高级感；设计一个管理员页面，充实其内容与完成度。
>
> **提交要求：** 仅能提交一个可在线访问的部署链接，确保作品已成功部署，而非仅本地运行。

围绕这个题目，我的出发点比较简单：合租的矛盾往往不是"钱算不清"或"地没人扫"本身，而是这些事没人愿意先开口。所以产品要做的不是加一个更精确的记账工具，而是把那些不好意思说的话，变成可以点一下的按钮。

## 功能设计

### 总览

进入首页先看到今天该关心的事：本月租金与租期倒计时、房管置顶的公告、自己今天有没有保洁任务、有没有没结清的钱。打扫打卡、物资告急、发起记账或提议都在这一页留了入口，不用翻菜单。

### 费用 AA 与债务平账

记账支持三种分摊方式：全员均摊、按各人实际金额精确分摊、按房间面积权重分摊（大额水电燃气一般用最后这种）。

比较麻烦的是结算。几个人轮流垫付之后，彼此之间会形成一堆零碎债务。这里实现了一个净额贪心算法（Min-Cash-Flow），把所有人对所有人的还款关系压成最少笔数——N 个人的多向债务最多 N-1 笔转账就能结清，不会出现 A 转 B、B 转 C、C 又转回 A 的情况。

另外支持一键结清两人之间的全部账单，以及按类别筛选（房租、电费、水气、宽带、日常物资、维修）。

### 保洁值日与换班

值日表按区域拆分：厨房操作台、洗手间浴室、客厅走廊、阳台垃圾。打卡时可以勾选具体细项，再补一句文字说明，比如"洗手池已消毒擦拭"。让室友看到确实做了，比只点一个"完成"更有说服力。

临时加班或出门，可以发起换班申请，指定日期和区域跟某人换，对方确认后值日表自动调整。此外有打卡率和准时率的统计，以及一键生成下一周排班。

### 公用物资

物资按库存分三档：充足、告急、断货。缺东西时可以一键生成一段清单文案，直接粘到微信群，比自己组织语言去说省事。

采购的人点"我已采购"，会直接弹出记账窗口，物资名称和类别已经填好，买完顺手就把账分了。

### 公约与投票

公约采用全员签署制，签满才生效。涉及大额添置或新规矩时发起投票，支持和反对都是公开的。

另外做了一面便签墙，用来表达生活感受，比如作息、访客这类不好当面讲的事，可以点赞，也可以标记为已处理。文案上刻意避开了"投诉""举报"这类词。

### 留言板

留言板与公约分开，这里只放日常内容：聚餐、提醒、夸夸室友、借东西、报备外出。支持匿名发布、点赞、多条回复盖楼，以及标记已解决。

### 房管后台

管理员页面是单独的一整块，包含：

- 房间管理：编号、面积、朝向、租金标准，以及对应的入住成员
- 全屋指标：总租金、租约剩余天数、收缴进度、保洁合规率、累计公共支出
- 成员管理：室友档案、房管权限指定、搬入搬出
- 公告发布：紧急与普通两档，可置顶全屋广播
- 操作日志：记录关键管理动作，数据乱了可以一键恢复到初始状态

### 界面

配色走低饱和的原木色系，浅米底色 `#FDFBF7` 配胡桃木棕 `#8B5E3C`，正文用柔和的咖啡色 `#2C2218`。夜间模式换成深暖灰（`#1C1917` / `#292524`）配琥珀金强调色。

系统文字（导航、按钮、状态、分类、公约条目）支持中英文切换。用户自己写的内容——留言、回复、备注、物品名、姓名——不进翻译层，保持原样。

## 两个实现上的细节

### 债务简化

先算每个人在所有支出中的 `实际支付 - 应分摊`，得到净盈或净欠；然后每一轮取应收最多的人和应付最多的人配对结算，直到所有人归零。

### 中英文隔离

翻译只作用于系统标识符，统一放在 `utils/i18n.ts`。用户产生的内容不翻译，避免出现人名被翻译这类问题。角色徽章是拼接出来的，比如 `房屋置顶公告 · 林晨 (房管)` 切到英文会变成 `Pinned House Announcement · 林晨 (House Admin)`，只有系统那一半会变。

## 本地运行

前端是 React + TypeScript + Vite，样式用 Tailwind，数据存在浏览器 LocalStorage 里，没有后端。

```bash
git clone https://github.com/ZXEQzzg/--AI-Coding-.git
cd --AI-Coding-
npm install
npm run dev        # http://localhost:3000
```

其它命令：

```bash
npm run lint       # 类型检查
npm run build      # 构建到 dist/
```
